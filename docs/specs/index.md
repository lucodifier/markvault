# Especificações Técnicas (Specs)

Índice das especificações de arquitetura e implementação geradas para o projeto **MarkVault**.

## Valores possíveis de status

| Status    | Significado                                                                                   |
| --------- | --------------------------------------------------------------------------------------------- |
| rascunho  | Em elaboração; o comportamento ainda não está fechado e a spec não está pronta para execução. |
| planejada | Aprovada e detalhada, aguardando implementação.                                               |
| executada | Implementada no código; a spec reflete o comportamento atual do sistema.                      |
| rejeitada | Descartada; não será implementada (ou foi substituída por outra abordagem).                   |
